导出功能生成的临时文件被别人抢先建好同名文件，导出内容直接写进了对方指定位置：候选名只用递增序号，可被预测并抢先占位；创建用普通打开模式，同名文件被直接覆盖；独占创建失败后回退到普通打开，竞态重新出现；写入后不做原子改名，中途失败留下半截文件；权限默认零七五五，其他用户可读；权限设置不校验模式位，允许零七七七；清理只删文件不校验路径是否在临时目录内；所有者校验只比较用户名字符串，同名用户被误判；批量导出复用同一候选名，第二个条目覆盖第一个；策略校验不检查目录是否可被他人写入。tmpfs/safe.py 是核心，tests/test_safe.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。
